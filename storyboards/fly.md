# 《飞》分镜

**一句话**：Clawd 想像蝴蝶那样飞，可它是个方块，怎么扇、怎么跳都摔；蝴蝶回来轻轻一碰，它才发现组成自己的每一笔都是一对翅膀——于是它起跳，散成一整群蝴蝶，穿过云层飞进金色的天空。

**世界**：两层。云下：灰紫色的阴天，山坡、一块石头、一道小崖。云上：金色的日出、云海。色彩弧线：冷灰紫 → 穿云的一片白 → 暖金、桃色、天蓝。

**母题**：翅膀。上一部《每一次》里那些会散开的"笔触"，在这一部里是会扑扇的翅膀；蝴蝶就是上一部里染上颜色的那一只。

**Clawd 的情绪线**：向往 → 不服气 → 努力 → 摔晕 → 难过 → 惊讶 → 困惑 → 使劲 → 灵光一现 → 看呆 → 下定决心 →（成群飞翔）→ 重新成形，开心 → 再次起飞。

**节奏**：100 bpm，一小节 2.4 秒；大事件落在小节线上（第一次扑腾 7.2，助跑起跳 12.0，摔下 14.4 前，蝴蝶回来 16.8，灵光 21.6，下蹲 24.0，穿云 28.8，成形 38.4，再次起飞 43.2）。

## 镜头

**A 向往 0.0–7.2** ［入：圆形光圈从蝴蝶身上打开］ 中全景，山坡顶。
- 0.0–3.0 蝴蝶在 Clawd 头顶绕飞；Clawd 的眼睛和身体跟着它转
- 3.0–4.6 蝴蝶盘旋上升，钻进云层不见了；Clawd 伸长了手去够
- 4.8–6.4 剩它自己。看看左手，看看右手，试着扇了两下
- 6.4 不服气

**B 努力 7.2–14.4** ［镜头推近，再跟着它跑］
- 7.2–8.3 拼命扇两只小短手；8.3 起跳，在空中多停了一瞬；8.95 落地，晕
- 9.6–10.8 看见右边的石头，后仰蓄力
- 10.8–12.0 助跑，冲上石头
- 12.0–12.55 从石尖跃出；12.55–13.0 悬在半空狂扇，往下一看，冒汗
- 13.0–13.6 掉下去（镜头甩着跟下去）；13.6 摔在崖下，冒金星

**C 那一下 14.4–24.0** ［崖下，近景］
- 14.7–16.6 坐起来，难过，头顶一朵小雨云
- 16.2–17.8 蝴蝶从上面飞回来，绕一圈，落在它头顶
- 18.4 蝴蝶轻轻点了两下；18.5–19.3 它头顶的一块颜色自己掀起来，扑扇，露出本来的颜色，又落回去
- 18.6–20.4 Clawd 惊讶 → 困惑
- 20.6–21.4 它闭眼使劲；21.35 另一块自己弹起来扑扇
- 21.6 灵光一现
- 22.2–23.4 头顶一整排一起扇：它离地悬了起来，低头看自己的脚；23.6 轻轻落地

**D 起跳 24.0–28.8**
- 24.0–24.55 深深下蹲（预备）
- 24.6 跳，很高；25.25 在最高点散成一群蝴蝶，每一只是它的一笔，带着各自的颜色
- 25.25–26.4 先四散，再聚成一股；跟着那只蝴蝶向上
- 26.4–28.8 冲进云层；画面被云填满 ［转场：穿云］

**E 云上 28.8–38.4**
- 28.8–30.2 云退下去，金色的天；蝴蝶群像喷泉一样从云海里涌出来
- 30.2–32.0 散开，铺满天空——自由
- 32.0–33.6 聚成 Clawd 的形状滑翔（两只深色的蝴蝶是眼睛），那只蝴蝶绕着它
- 33.6–36.4 俯冲，贴着云顶掠过，再拉起来绕一个大弯
- 36.4–38.3 落向一朵云，收拢

**F 落下，再起飞 38.4–45.6** ［出：飞进太阳，画面化成一片暖光］
- 38.4 「啵」——Clawd，站在云上（云被踩得一沉）
- 39.0–40.2 睁眼，看见日出
- 40.0 蝴蝶落在它头顶
- 40.8–41.5 它让头顶那排翅膀扇了一下——现在它知道了
- 42.4 蝴蝶朝太阳飞去；43.0 Clawd 下蹲，43.2 起跳，43.55 再次散成蝴蝶群
- 43.55–45.2 一起飞向太阳，越来越小；光漫开
